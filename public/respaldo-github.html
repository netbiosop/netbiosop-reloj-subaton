El token se guarda solo en esta PC (archivo respaldo-github.json) y nunca se sube.

Cómo prepararlo (una sola vez)

  1. Crea un repositorio privado en github.com/new (ej. reloj-respaldos, marca Private).
  2. Crea un token en github.com/settings/personal-access-tokens/new:
    • Expiration: la más larga que te deje (o "No expiration").
    • Repository access: Only select repositories → elige solo el repositorio privado.
    • Permissions → Repository permissions → Contents: Read and write.
  3. Toca Generate token, cópialo y pégalo arriba junto con el nombre del repositorio.
Se sube: subs, bits, donaciones, podio, metas y ajustes. Nunca se suben tus claves, tokens ni contraseñas. Cada copia queda como una versión en el historial del repositorio.
